# 0.3.37 CNKI recovery validation — 2026-10-03

Browser 0.3.37 · Native plugin 0.5.6. Local verification only; GitHub publication awaits release-text approval.

## Fixes

- A forced same-page detection refresh now waits for a stale in-flight DOM copy, then uses the current document. Concurrent requests coalesce, and navigation discards obsolete work.
- Verification classification uses explicit verification routes or exact verification titles without article metadata. Normal article titles containing CAPTCHA-related words remain usable.
- Missing CNKI snapshots are captured with the existing SingleFile engine and stored under the identified native parent. Repeat saves reuse existing snapshots.
- Native tests require a completed boolean `ok: true` report with the final installed XPI hash. Missing, failed, mismatched and timed-out reports fail. Controlled-page success alone cannot turn blocked real-page acceptance green.

## Real CNKI acceptance

An isolated Edge profile and Zotero 9.0.6 library used the unchanged supplied CNKI Translator on [黄瓜胚性愈伤组织的诱导保存和再生](https://link.cnki.net/doi/10.13207/j.cnki.jnwafu.2024.07.011).

- First save created a journal article, a PaperLoop note and a readable 617,177-character HTML Snapshot.
- Title, six authors, DOI, journal, year 2024, volume 52, issue 7 and pages 99–105 matched the current live page. The page's “附视频” control is not part of the article title, and full-/half-width journal parentheses are normalized for comparison.
- Repeat saving reused the parent, note and snapshot keys.
- Actual closed-shadow sidebar controls received pointer/keyboard input: save, close/reopen, insert another edit and save. The final native note retained those inserted markers. This is not a test of replacing all text with Ctrl+A.
- The full Snapshot contains the article title and does not contain the PaperLoop sidebar host.
- A separate generated CNKI page with metadata arriving after 5.5 seconds completed actual Translator → Connector → Zotero note/Snapshot saving, then updated the same note without a second snapshot.

The comprehensive real-page/controlled-page result reports one real page passed and the controlled page passed. An earlier first-save run failed a test assertion that included the page's “附视频” label in the expected title; its saved metadata was correct. That failed run supplies first-creation evidence only, not a whole-run pass.

The user-provided encrypted link and two other CNKI links reached security verification in earlier runs. Their article saving is not confirmed. Actual DOI-less/thesis CNKI pages and live ScienceDirect/Wanfang saves are not newly verified by this update. Controlled fixtures do not imply all publishers or Translator versions pass.
