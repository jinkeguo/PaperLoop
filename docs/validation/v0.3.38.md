# 0.3.38 save and recovery validation — 2026-10-03

Browser 0.3.38 · Native plugin 0.5.7. Local verification; GitHub publication awaits release-text approval.

## Fixes

- Commit rich notes and images before snapshot supplementation. Bound capture to 20 seconds and the background request to 45 seconds; require an explicit acknowledgement, and permit retry after timeout or disconnection.
- Protect initial draft loading against early typing, saving and image operations. Closing during initialization does not replace the unread draft.
- Preserve backup image captions, dimensions and capture order. Validate mapped native attachments and replay retained image bytes when a mapping is no longer usable.
- Limit each detection generation to 20 seconds, discard late outcomes and let retries start fresh. Exclude legacy CNKI search routes from automatic display.
- Only existing imported-URL HTML/XHTML attachments with an HTTP(S) source count as reusable webpage snapshots. Ordinary local HTML files do not suppress snapshot capture.
