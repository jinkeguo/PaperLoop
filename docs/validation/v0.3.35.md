# 0.3.35 interaction regression — 2026-09-29

## Reproduced before fixing

- Save and Add images changed from the accent color to the pale hover color in all seven themes and both modes. Example: light cowcat `rgb(42,44,48)` → `rgb(251,239,239)`.
- First input without a preceding paragraph click could leave Delete current paragraph disabled.
- A render between pointer press and release removed/recreated the inline paragraph delete button, losing the click.
- An in-flight automatic save disabled Add/Delete even though typing remained allowed.
- Blurring an image-name input rebuilt the gallery before the next button received its click.

## Fixes

- Lower-specificity generic hover plus explicit themed primary-button states.
- Select the edited paragraph on input, including paste/IME-style commits without keyup.
- Keep paragraph buttons and unchanged image-reference chips mounted across renders.
- Allow paragraph edits during automatic saves; use the existing revision-aware merge and follow-up save. Manual saves and image writes retain their locks.
- Defer gallery replacement during a pointer interaction, commit rename before the selected click action, and render after release. Ignore element blur when handling actual window-focus loss; detach listeners on disposal.
