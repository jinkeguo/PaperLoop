# PaperLoop 0.3.41 Claude 审核与验证

2026-10-06 验证，2026-10-08 更新文案经用户确认。浏览器 0.3.41，Zotero 插件仍为 0.5.7。已整合 Claude 对 0.3.40 的有效修复，并补上数据迁移与异步保存的保护。

## 审核结论

| Claude 的判断或修复 | 审核结果与处理 |
| --- | --- |
| 向所有 iframe 广播保存，非目标框架可能先返回空值 | 确认。真实隔离 Edge 扩展复现空响应抢先返回。PaperLoop 保存只发送给检测到 Translator 的框架，保留标准 Connector 的原有行为。框架身份缺失时明确报错。 |
| 保存、快照与隐藏页面可能一直等待 | 采纳并补强。文献保存等待 180 秒，快照捕获 60 秒，隐藏页面捕获 20 秒；侧栏 240 秒无进度后解除等待。清理隐藏页面也不能阻塞超时退出。 |
| 同路径的查询参数变化可迁移草稿与图片 | 原方案过宽，会把新增文章 id 当成原文章。改为只忽略已知追踪参数；id、v、filename 等变化仍视作不同页面。 |
| 草稿冲突可按时间取较新版本 | 不采纳静默覆盖。新地址已有不同草稿或关联另一文献时停止迁移，保留两边内容。复制所有文库的草稿，而不只是当前文库。 |
| 移动未忙碌的图片即可 | 补强。源地址和目标地址共同加锁；待存图片、备份历史和备份图片在一个 IndexedDB 事务中移动，失败整体回滚。 |
| 重试可以复用进行中的保存 | 仅相同文献、内容与保存目标可复用。不同请求明确提示上一笔仍在进行，避免返回别的保存结果。空数组也不能算保存成功。 |
| 图片锁定、输入法失焦与重连问题 | 采纳并补充丢失进度事件后的解锁；本地图片操作仍保留锁。重连及同步、异步消息派发失败均结束旧等待。 |
| 本机草稿依赖自动备份完成 | 解除依赖。浏览器本机草稿先写入，备份单独处理，备份失败不阻止后续草稿保存。 |
| 保存看门狗解除等待 | 增加运行序号校验。旧请求晚到的成功或 409 错误不能覆盖新面板或重试旧保存。 |

超时是停止等待，不代表取消已经发给 Zotero 的写入。后台仍保留实际保存锁，避免超时后重复创建。图片三库迁移是原子的；浏览器 local storage 与 IndexedDB 之间不是跨存储事务，因此本机原稿和原关联始终保留。

## 本次验证

- 19 个命令行回归文件通过，包括新增保存可靠性文件的 15 项检查。
- 新增 8 项隔离 Edge 检查通过：追踪参数迁移、不同文章隔离、目标草稿冲突、强制事务中断、文献关联冲突、备份阻塞、本机草稿、输入法及超时旧请求隔离。
- 真实 Edge MV3 消息通道的 3 项检查通过：广播时非目标框架在 1 ms 返回空值；定向主框架与子框架分别在 352 ms、353 ms 返回正确结果。使用真实生产监听器及路由函数，Translator 结果为延迟测试数据，不连接 Zotero。
- 最终合并回归共 196 项隔离 Edge 检查通过，包含原有 188 项及新增 8 项。涵盖笔记输入、图片增删与关联、备份恢复、同步冲突、主题、宠物及拖动缩放。

完整回归曾在“删除待存图片”场景等待图片数量时失败。前一场景的打字启动了自动保存，提前保存了后一场景的图片。测试改为先完成前一笔保存，再验证图片暂存与撤销；没有延长超时或关闭生产自动保存。这不支持把失败归因于 D 盘路径。

## 验证范围

浏览器测试使用隔离 Edge、真实 DOM 和 IndexedDB，以及测试用 Zotero 对象，不读取个人文库。Claude 交付的 arXiv、Nature、Springer 等实站日志属于其报告，本次没有作为独立实站验证结果。未运行会写入个人文库的 live.cjs。

本次没有重新验收知网、ScienceDirect 等实站保存；验证码页面不是文献提取成功。Zotero 7.0.32、8.0.4、9.0.6、10.0.3 的既有原生测试仍见 [兼容性说明](../COMPATIBILITY.md)，不是本次新增的四版本实测。

Translator 定义、提取引擎与编译器未改动；本次改动涉及浏览器保存消息、快照捕获等待和 PaperLoop 数据管理。知网 Translator SHA256 仍为 `12531C118225B7E8F3FCD6019425F89CB3896381D60FE63598C88C1B605F0180`。主题和宠物素材不变。
