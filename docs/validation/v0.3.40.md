# 0.3.40 themes and browser companions — 2026-10-04

Browser 0.3.40 · Native plugin 0.5.7 (unchanged). Local build; GitHub publication awaits release-text review.

## Changes

- Three additional full palettes: Sakura Cat, Apricot Shiba and Sea Salt Sunset. Each supports light/dark appearance and both existing illustration styles. Existing header artwork is reused; the pet artwork is separate.
- Minimize to an original animated cow cat or Shiba. Drag anywhere within the viewport, click or press Enter/Space to return to the notebook. Pet and notebook coordinates are persisted separately. Manual pet selection and the classic ribbon are available in settings.
- Local SVG artwork provides blinking, breathing and tail motion. Both animals stop animating with the system's reduced-motion preference. No sound, remote asset requests, cursor chasing or desktop-wide window is added.
