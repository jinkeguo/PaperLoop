# PaperLoop 0.3.31

本地修复版，Zotero 插件仍为 0.5.4。

- 点击“新的一段”后直接输入普通正文，继承当前字体选择；不再添加默认标题文字。
- 自动保存内容未变化时不重建编辑区，保留光标，继续在原段落输入。
- 空白提示按实际文字内容显示，修复首字出现在空段落前时，提示没有消失的问题。空段落保留有效的输入位置。
- 保留旧笔记的标题、富文本和图片；未改编译器或 Zotero 插件。

测试使用隔离浏览器中的鼠标点击、实际键盘和中文组合输入，包括自动保存后连续输入、从加粗标题切换到普通段落，以及首次输入提示消失。未写入个人文库。

## English

New paragraphs start with body text and inherit the selected font without a generated title. Automatic save responses with unchanged content no longer replace the editor DOM or reset the caret. Empty-note help is based on actual content, including text nodes placed before a blank paragraph. Existing headings, rich text and images remain intact.

Reload the extension and refresh paper pages. The compiler and native Zotero plugin are unchanged. This local build is not published to GitHub.
