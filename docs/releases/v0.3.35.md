# PaperLoop 0.3.35 · Zotero 0.5.5

## 中文

- 支持 Zotero 7–10，修复 Zotero 7 打开笔记时旧内容覆盖新保存内容的问题。
- 更新整体界面，提供奶牛猫、柴犬等七套主题，支持墨线淡彩、透明水彩与深浅色外观。
- 支持粘贴截图、导入本地图片和拖入图片，保存后不再混入尺寸、来源等多余文字。
- 修复首次输入提示残留、段落字体、按钮无响应和自动保存后光标跳走。
- 修复添加图片、保存按钮变白，以及图片改名后下一次点击失效。
- 增加面板大小按钮、本机自动备份与恢复，保留图文同步和 Zotero 两栏笔记。

感谢 Zotero Note Editor、ProseMirror、DOMPurify 的维护者与贡献者。

## English

- Supports Zotero 7–10 and fixes stale open-editor content overwriting new saves in Zotero 7.
- Refreshes the interface with seven themes, including Cow Cat and Shiba, with ink-and-wash, transparent watercolor, and light/dark appearances.
- Adds screenshot paste, local image import and drag-and-drop, without unwanted size or source text in saved notes.
- Fixes leftover prompts, paragraph fonts, unresponsive buttons and caret jumps after autosave.
- Fixes washed-out Add images and Save buttons, and clicks lost after image renaming.
- Adds panel size controls and local backup/recovery, retaining text/image synchronization and two-column Zotero notes.

Thanks to the maintainers and contributors of Zotero Note Editor, ProseMirror and DOMPurify.
