# PaperLoop 0.3.39 · Zotero 0.5.7

更新说明草稿，待审核 / Draft release notes for review

## 中文

- 草稿记录所属文库，避免自动保存到其他文库。
- 备份包含已保存图片，恢复时保留图片和关联。
- 恢复旧版本不再混入后来添加的图片；这些图片会另存备份。
- 临时断线或权限错误不再清除有效图片关联。

Zotero 插件仍为 0.5.7，本次只需更新浏览器扩展。

## English

- Bind drafts to their Zotero library to prevent saving into another library.
- Include saved images in backups and preserve their links during recovery.
- Keep later-added images out of restored versions and preserve them in a separate backup.
- Preserve valid image mappings during temporary connection or permission errors.

The Zotero plugin remains at 0.5.7. Only the browser extension needs updating.
