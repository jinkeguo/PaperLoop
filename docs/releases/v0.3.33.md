# PaperLoop 0.3.33 · Zotero plugin 0.5.5

## 中文

- 支持 Zotero 7–10，修复 Zotero 7 打开笔记时旧内容覆盖新保存内容的问题。
- 更新整体界面，提供奶牛猫、柴犬等七套主题，可切换墨线淡彩与水彩拼贴。
- 支持粘贴截图、导入本地图片和拖入图片，保存后不再混入尺寸、来源等多余文字。
- 修复首次输入残留提示、新段落字体异常、文字遮挡按钮和自动保存后光标跳走。
- 增加面板放大、缩小、适应窗口，以及本机自动备份与恢复。
- 保留图文同步和 Zotero 两栏笔记，改善文献页自动显示。

感谢 Zotero Note Editor、ProseMirror、DOMPurify 的维护者与贡献者。

## English

- Supports Zotero 7–10 and fixes stale open-editor content overwriting new saves in Zotero 7.
- Refreshes the interface with seven themes, including Cow Cat and Shiba, in ink-and-wash or watercolor-collage styles.
- Adds screenshot paste, local image import and drag-and-drop, without unwanted size or source text in saved notes.
- Fixes leftover prompts, incorrect new-paragraph fonts, overlapping controls and caret jumps after autosave.
- Adds panel size controls, fit-to-window, and local backup and recovery.
- Retains text/image synchronization and two-column Zotero notes, with improved automatic display on paper pages.

Thanks to the maintainers and contributors of Zotero Note Editor, ProseMirror and DOMPurify.
