# PaperLoop 0.3.29

浏览器扩展 0.3.29 · Zotero 插件 0.5.4。此版本目前为本地安装包，未发布到 GitHub。

## 中文

- 图片：可右键收网页图片，也可在笔记里粘贴截图、点击“添加图片”或拖入本地图片。最后使用同一个“保存到 Zotero”按钮。
- 编辑：先插图也能继续输入；新段落的标题提示不会存为正文。
- 面板：使用“−”“＋”“适应”调整窗口大小，保留拖动和手动缩放。
- 备份：点击“备份”查看最近 20 个本机版本，也可“立即备份”。恢复前会保留当前版本，恢复后检查内容再保存到 Zotero。
- 恢复：浏览器数据清空后，打开原文献并选择原文库/分类，即可载入已保存的 Zotero 笔记；也可使用“备份 → 从 Zotero 载入”。未同步的本机内容无法从 Zotero 找回。
- 主题：整体主题中新增 Claude · 暖纸、Claude · 雾松、Claude · 墨蓝，支持浅色和深色。
- 自动显示：文献详情页可在网页提取器启动期间显示面板，搜索结果页仍不自动显示。

本机备份属于扩展数据。清除扩展数据、卸载扩展或更换扩展身份可能使本机备份丢失。版本按文献和所选分类保存；已同步图片通过 Zotero 附件载入。没有新增云服务。

## English

- Paste screenshots, select local images or drop files into the panel. The main Save to Zotero button saves both text and images.
- Start typing after adding images; placeholder titles no longer become note content.
- Resize the panel with Smaller, Larger and Fit controls.
- Keep up to 20 local versions. Recovery first preserves the current version and waits for an explicit save after review.
- After local browser data loss, reopen the paper and select its original library/collection to load the saved Zotero note. Unsynced local content cannot be recovered from Zotero.
- Choose Warm Paper, Sage or Ink Claude-inspired themes in light or dark mode.
- Literature detail pages can display the notebook while metadata detection starts. Search results stay manual.

Local history is extension data, not a separate cloud backup. Clearing extension storage, uninstalling the extension or changing its identity can remove it. Versions are scoped to the page and selected collection.

## 安装 / Install

首次安装：在 Zotero 插件管理器中安装 `PaperLoop-for-Zotero-0.5.4.xpi`。浏览器开启开发者模式后，加载安装包内的 `browser-extension` 文件夹。

已有用户：先保存笔记，备份原扩展文件夹，将新文件覆盖到同一个文件夹，然后在扩展管理页重新加载并刷新文献页。已安装 Zotero 插件 0.5.4 的用户无需重装 XPI。

For a first install, install the XPI through Zotero's Plugins manager and load the browser-extension folder as an unpacked extension. To upgrade, save notes, back up the old folder, replace its files in place, reload the extension and refresh webpages. Zotero plugin 0.5.4 is unchanged.

## 验证 / Validation

- 105 checks in isolated headless Edge, covering actual keyboard input, clipboard/file data, IndexedDB history, restore, full simulated local data loss, themes, sync and images. Zotero library objects in these checks are test doubles.
- 11 Node regression files, including 9 translator fallback/save scenarios and 8 new early-display scenarios.
- 7 theme-library checks covering 14 appearances, side-by-side layout, image interactions, sizing, narrow viewports and offline opening.
- Native XPI is unchanged from 0.5.4; the previous 18 real Zotero runtime checks were not rerun for this browser-only update.
- Translator definitions, extraction helpers and the supplied compiler are unchanged. Live publisher pages, including authenticated CNKI pages, still need user acceptance testing.

Color direction references [Claude](https://claude.com/). PaperLoop uses original palettes and installed system fonts; no Claude logo or proprietary font files are bundled. Existing editor and photo contributor credits remain in NOTICE.md, docs/CREDITS.md and the photo source files.
