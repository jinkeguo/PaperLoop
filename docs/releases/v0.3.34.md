# PaperLoop 0.3.34

## 中文

- 水彩插画改为透明底，保留白色毛发和浅色细节。
- 插画周围加入随主题变化的柔和渐变，适配深浅色外观。

仅更新浏览器扩展；Zotero 插件仍为 0.5.5。

## English

- Watercolor illustrations now have transparent backgrounds while retaining white fur and pale details.
- Added a soft, theme-colored gradient behind illustrations in light and dark modes.

Browser extension update only; the Zotero plugin remains at 0.5.5.
