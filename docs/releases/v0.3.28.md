# PaperLoop 0.3.28

浏览器扩展 0.3.28 · Zotero 插件 0.5.4

[完整分享包 / Complete package](https://github.com/jinkeguo/PaperLoop/releases/download/v0.3.28/PaperLoop-0.3.28-Share.zip) · [浏览器扩展 / Browser extension](https://github.com/jinkeguo/PaperLoop/releases/download/v0.3.28/PaperLoop-Browser-Extension-0.3.28.zip) · [Zotero 插件 / Zotero plugin](https://github.com/jinkeguo/PaperLoop/releases/download/v0.3.28/PaperLoop-for-Zotero-0.5.4.xpi)

## 中文

- 修复普通编辑后误报“两端内容不一致”。
- 已关联的笔记自动双向同步，不同段落的修改自动合并。
- 修复多张图片在重新打开文献后不显示缩略图的问题。

首次收藏仍点击“保存到 Zotero”。之后浏览器停止输入约 2 秒自动保存；Zotero 修改会在切回网页或约 5 秒内同步到浏览器。两端同时改动同一处、无法安全合并时，可以选择保留哪一版，两版均会备份。

升级时保留原浏览器扩展文件夹，用新版文件覆盖，再重新加载扩展并刷新文献页。Zotero 端继续配套 0.5.4。不要卸载扩展或清除站点数据。

## English

- Fixed false conflicts after ordinary note edits.
- Linked notes sync both ways and automatically merge changes to different paragraphs.
- Fixed missing thumbnails when reopening papers with multiple saved images.

Save a paper explicitly the first time. Browser edits then save after about two seconds of inactivity; Zotero edits appear when returning to the page or within about five seconds. Overlapping edits that cannot be safely merged offer a choice and back up both versions.

Replace files in the existing browser extension directory, reload the extension, and refresh paper tabs. Continue using Zotero plugin 0.5.4. Keep the extension installed to preserve local drafts.
