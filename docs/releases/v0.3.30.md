# PaperLoop 0.3.30

本地修复版，未发布到 GitHub。Zotero 插件仍为 0.5.4，无需重装。

## 修复内容

- 截图和本地图片保存后，不再把“image · 宽 × 高”和“图片来源”写成笔记段落。
- 识别 Zotero 清理样式标记后的图片说明，以及旧版已导出的同类多余段落；保留用户正文和手写尺寸记录。
- 截图和本地图片不再把当前文章网址当成图片来源。
- 空白笔记提示说明：Win + Shift + S 截图，然后 Ctrl + V 粘贴；本地文件可通过“添加图片”或拖入，最后点击“保存到 Zotero”。提示文字不会写入笔记。

重新加载扩展并刷新文献页后生效。打开旧笔记会清理能够准确识别的自动说明；保存后写回 Zotero，不批量改动文库。

## English

- Fixed generated dimensions and provenance becoming editable paragraphs when Zotero strips custom classes.
- Recoverable metadata-only rows from previous exports are cleaned while ordinary note text and measurements are preserved.
- Local images no longer use the current article URL as their provenance.
- The empty-note prompt now explains screenshots, paste, local files and saving. Help text is never saved as note content.

Reload the browser extension and refresh paper pages. Zotero plugin 0.5.4 and the supplied translator/compiler remain unchanged. No personal library was used in automated tests. This build is not published to GitHub.
