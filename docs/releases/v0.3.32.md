# PaperLoop 0.3.32

修复空白笔记提示覆盖“新的一段 / 删除本段”。此前的提示使用绝对定位，多行内容不计入编辑区高度，会越过按钮位置。

提示改为独立、不可编辑的布局层，与编辑区共同参与高度计算；段落按钮移入独立操作栏。提示不会保存为正文，开始输入后仍会隐藏。普通字体、手写字体、窄面板和页面缩放均做了边界检查。

新增 12 项布局和点击检查，包含长正文、多段输入、删除后的空白状态、150%/200% 缩放，以及按钮真实鼠标点击。完整浏览器回归共 126 项。截图在隔离测试环境检查，不操作个人文库。

## English

Fixed empty-note help overlapping the new/delete paragraph buttons. Help now participates in layout sizing instead of being absolutely positioned, and paragraph controls have a separate action row. Help remains outside editable content and is never serialized into notes.

Added 12 layout/click checks covering normal and handwriting fonts, narrow panels, long text, paragraph addition/deletion, 150%/200% zoom and real mouse input. Native Zotero plugin 0.5.4 and the supplied compiler are unchanged. Reload the extension and refresh paper pages to use this local build; no GitHub publication.
