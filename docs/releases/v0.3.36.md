# PaperLoop 0.3.36 · Zotero 0.5.6

## 中文

- 改进知网文献识别，等待动态加载的文献信息，避免重复识别相互干扰。
- 区分页面加载、安全验证和识别异常，保留本机草稿。
- 保存知网文献时补存网页快照，已有快照直接复用，失败后可再次保存重试。

感谢 Zotero Note Editor、ProseMirror、DOMPurify 的维护者与贡献者。

## English

- Improves CNKI detection by waiting for dynamically loaded metadata and sharing concurrent detection requests.
- Shows clearer messages for loading, verification and detection errors while retaining local drafts.
- Adds webpage snapshots when saving CNKI articles, reuses existing snapshots and allows failed captures to be retried.

Thanks to the maintainers and contributors of Zotero Note Editor, ProseMirror and DOMPurify.
