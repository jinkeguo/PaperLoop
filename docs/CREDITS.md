# 致谢 / Credits

感谢以下项目的维护者与贡献者。 / Thanks to the maintainers and contributors of:

- [Zotero Note Editor](https://github.com/zotero/note-editor)：Zotero 原生笔记编辑器，PaperLoop 的原生图文笔记与之兼容。 / The native editor used by Zotero for PaperLoop notes.
- [ProseMirror](https://github.com/ProseMirror/prosemirror)：Zotero 笔记编辑器的基础。 / The editing framework underlying Zotero's note editor.
- [DOMPurify — Cure53 and contributors](https://github.com/cure53/DOMPurify)：浏览器端笔记 HTML 清理。 / Sanitizes note HTML in the browser.
- [Zotero Connector](https://github.com/zotero/zotero-connectors) 和 [Zotero Translators](https://github.com/zotero/translators)：网页识别、题录与附件提取。 / Page detection, metadata and attachment capture.

浏览器端编辑区使用原生 contenteditable；没有把 ProseMirror 作为浏览器端编辑器打包。 / The browser editing area uses native contenteditable; ProseMirror is not bundled as its browser editor.
