# PaperLoop for Zotero 0.5.5

[中文说明](#中文) · [English](#english)

## 中文

与 PaperLoop 浏览器扩展 0.3.33 配套使用。

- 将图文保存为 Zotero 原生笔记与图片附件。
- 笔记采用左侧文字、右侧关联图片的两栏排版。
- 保留可编辑 PDF 摘录、笔记内 @文献和文献关系数据接口。
- 没有填写思考时仍可创建笔记，不会清空已有文字。

在 Zotero 插件管理器中从文件安装 `PaperLoop-for-Zotero-0.5.5.xpi`，重启后使用。详细操作见 [安装与更新](../docs/INSTALLATION.md)。

支持 Zotero 7–10。实测版本与范围见 [兼容性记录](../docs/COMPATIBILITY.md)。目前通过 XPI 手动更新，不提供自动更新。

## English

Use with PaperLoop Browser Extension 0.3.33.

- Saves text and images as native Zotero notes and image attachments.
- Displays text on the left and associated images on the right.
- Retains editable PDF excerpts, @literature mentions, and the literature-graph endpoint.
- Creates notes when the thought field is empty without clearing existing text.

Install `PaperLoop-for-Zotero-0.5.5.xpi` through Zotero's Plugins manager and restart Zotero. See [installation and upgrade](../docs/INSTALLATION.md).

Supports Zotero 7–10. See [tested versions and scope](../docs/COMPATIBILITY.md). Updates are installed manually via XPI.
