# PaperLoop for Zotero 0.5.4 / Zotero 9 手工验收

> 自动测试已经通过；本清单用于真实 Zotero 界面、保存和插件共存复验。

## 1. 安装

1. 打开 Zotero“工具 → 插件”，从文件安装。
2. **选择 `PaperLoop-for-Zotero-0.5.4.xpi`，不要选择说明文件或源码目录。**
3. 重启后确认插件列表显示 `PaperLoop for Zotero 0.5.4`，且没有“不兼容”或“已禁用”提示。
4. 在“帮助 → 关于 Zotero”确认本轮目标主机为 Zotero 9.0.6。

## 2. 空思考也必须创建笔记

1. 在浏览器 PaperLoop 侧栏选择测试分类，不填写“阅读思考”，直接保存。
2. 确认 Zotero 文献条目下仍出现标题为 `PaperLoop 思考` 的子笔记。
3. 在该笔记中写入文字，再从浏览器用空思考保存同一篇文献，确认已有文字没有被清空，也没有新增重复笔记。

## 3. 摘录必须可上色

1. 打开一篇 PDF，选中一句话，点击 `可编辑摘录`。
2. 确认笔记中出现两部分：普通摘录正文；短的 `↩ 返回原文 · p.X`。
3. 只选中摘录正文中的几个字，确认出现 PaperLoop 颜色浮条；分别测试文字颜色和背景填充，再测试“清除颜色”。加粗仍可使用 Zotero 原生工具栏。
4. 预期只有选中的字变化；整段不是不可拆分的高亮对象。
5. 编辑或删除正文中的几个字，再点击 `↩ 返回原文`，预期仍定位到原 PDF 选区。
6. 完全退出并重启 Zotero，再点击返回入口，预期仍精确定位。

## 4. 笔记中 @ 其他文献

1. 在当前文献的子笔记中输入 `@` 加另一篇文献标题或作者的一部分。
2. 确认面板顶部有独立搜索框，以及无需展开的“全部分类”和具体分类按钮；使用中文输入法完整输入至少两个汉字，确认拼音组合过程没有被中断，再尝试英文多词查询。
3. 确认面板显示“已显示 X / 共 Y 条”；候选显示题名、作者/年份、文库与 Zotero 分类，且不会列出当前文献本身。
4. 确认现有 Zotero 分类直接显示为按钮；空分类也应列出，子分类显示为“父分类 / 子分类”。点击一个分类后，该按钮应有清晰选中态。
5. 选择一个含文献的具体分类，确认只显示该分类条目；再输入搜索词，确认搜索与分类组合生效。若命中超过 50 条，点击“加载更多”并确认数量继续增加。
6. 测试方向键 + Enter；再测试鼠标选择。
7. 选择一篇带 PDF 的文献，候选应显示“点击打开 PDF”；点击插入后的 `@作者, 年份 — 标题`，预期 Zotero 直接打开目标 PDF。
8. 选择一篇没有 PDF 的文献，候选应显示“无 PDF · 定位条目”；点击后预期 Zotero 定位目标文献条目。
9. 点击一个由 0.4.4 或更早版本插入的旧 PaperLoop 文献链接；若该文献现有 PDF，预期 0.5.0 也直接打开 PDF。
10. 若有群组库文献，再分别测试跨文库 PDF 打开或条目定位。

## 5. 关系数据

先建立至少两条关系，例如 A 的笔记 `@B`、B 的笔记 `@C`。保持 Zotero 正在运行，在交付目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\GET-LITERATURE-GRAPH-0.5.0.ps1
```

预期 JSON 中：

- `nodes` 包含 A、B、C 的题录身份；
- `edges` 包含 `A -> B`、`B -> C`，类型为 `mentions`；
- 同一来源重复 `@` 同一目标时不产生重复边，而是增加 `mentionCount`；
- 输出不包含笔记正文、摘录正文或 PDF 内容。

## 5. 兼容与回归

- Zotero 9.0.6 启动和退出时不出现 PaperLoop JavaScript 错误；禁用再启用插件后功能能恢复，端点不会重复注册。
- 在 PDF 阅读器中重复打开/关闭文档后，`可编辑摘录` 按钮不应重复出现。
- Translate for Zotero 的翻译与原按钮仍正常。
- Better Notes 的加粗、颜色及原笔记功能仍正常。
- PaperLoop 浏览器收藏/DOI 查重流程仍正常。
- 快速双击 `可编辑摘录` 不应插入两份相同选区。

## 反馈四项结果

1. 摘录局部加粗/上色是否成功。
2. 重启后返回原文是否精确。
3. `@` 候选、插入和点击定位是否成功。
4. 关系 JSON 是否包含预期边。

若需回退，在插件管理器安装 `PaperLoop-DOI-Bridge-0.1.19-rollback.xpi` 并重启。回退不会删除已有笔记内容。

若候选选择后仍未插入，请记录候选框显示的错误码，并运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\GET-LITERATURE-MENTION-STATE-0.5.0.ps1
```

诊断 JSON 只含版本、计数、分类来源、按钮数、点击/选择次数、阶段、错误码及 Zotero 对象 key，不含分类名称、查询词和笔记正文。真实分类读取成功时，`catalog.options` 与 `collectionUI.renderedButtons` 应大于 0。
